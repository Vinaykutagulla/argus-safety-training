## 🎯 DAILY TRAINING FLOW

### Every Day Follows This Structure:

**8:00 AM - Review & Learning (30 min)**
```
1. What did we learn yesterday? (5 min review)
2. Today's learning objective (5 min intro)
3. You teach the concept (15 min) - use real examples
4. Student reads the material (5 min)
5. Questions? (5 min) - answer everything
```

**8:30 AM - Hands-On Practice (60 min)**
```
1. You demonstrate the task once (5 min)
2. Student does it while you watch (50 min)
3. They complete the workbook exercise (5 min)
4. You help if they get stuck (ongoing)
```

**10:00 AM - Review & Feedback (30 min)**
```
1. Check their work (10 min)
2. Ask comprehension questions (10 min)
3. Give specific feedback (5 min)
4. Prepare for next day (5 min)
```

Use these questions:
- "Can you find [feature] without help?"
- "What's the deadline rule here?"
- "Why is this case serious?"

- Process 3 cases correctly

**Week 4 Assessment:**
- Regulatory requirement exercise
- Deadline calculations
- 80%+ required

- Covers everything learned

## 📞 IF THINGS GO WRONG

### Student Struggling:
```
1. Identify specific weakness
2. Review that concept
3. Extra practice on just that skill
4. Retest when ready
5. Move forward when confident
(Don't let them fall behind unprepared)
```

### Student Failing Assessment:
```
1. Don't advance to next week
2. Identify what they didn't understand
3. Teach again with different examples
4. More exercises
5. Retest (must pass before advancing)
```

### Student Missing Concept:
```
- Ask them to explain it back to you
- Where are they confused?
- Use different example
- Draw it on whiteboard
- Have them teach it to you
```
